# Платформа АРХИ — демостраница

Демонстрационная страница Платформы АРХИ — платформы контроля строительных регламентов:
что она делает, как выглядит и что даёт. Само изделие работает локально и в этом
репозитории не лежит.

| Адрес | Для чего |
|---|---|
| <https://archi-nsu.vercel.app/> | основной |
| <https://barbashin1970.github.io/ARCHI-NSU-Public/> | открывается из России без VPN |

Push в `main` обновляет оба адреса: Vercel публикует корень как есть, GitHub Pages — копию
с адресами под подпапку (`.github/workflows/pages.yml`, `tools/dlya_pages.py`, разбор —
`docs/PAGES-DUBL-RAZBOR.md`). Оформление переносится из изделия командой
`./obnovit-iz-izdeliya.sh`.
